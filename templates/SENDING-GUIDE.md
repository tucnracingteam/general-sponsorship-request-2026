# Send the sponsor page as an email

The message body should use the rendered `index.html` design. Do not use a separate sponsor-outreach template. Open the published page in a browser and copy its displayed content into Thunderbird. Email apps may adjust some webpage styling; test the result before sending it to sponsors.

## Before sending

The new repository is `tucnracingteam/general-sponsorship-request-2026`. Its GitHub Pages publishing source is `main` and `/(root)`. The public page URL is:

`https://tucnracingteam.github.io/general-sponsorship-request-2026/`

Check that the page, images, and PDF load from that URL before composing the email.

## Copy the page into Thunderbird

1. Open the **published URL above** in Safari or Chrome. Do not use a local `file://` preview; that can copy links to files on your computer.
2. Click in the page, press **Command+A**, then **Command+C** on Mac (or **Ctrl+A**, then **Ctrl+C** on Windows). This copies the rendered page, not the HTML source.
3. In Thunderbird, start a new message. In **Account Settings → your sending account → Composition & Addressing**, make sure **Compose messages in HTML format** is enabled.
4. Click in the message body and use normal **Paste** (not **Paste without formatting**). The page may not look identical in every email app; Gmail can adjust spacing, fonts, and some layout styles.
5. Address the message to yourself and use the subject **Parteneriat pentru Australia | TUCN Racing Team**. Send it as a test.
6. Open the test in Gmail on desktop and phone. Check the hero photo, the Australia contact button, and the PDF link. If the page is too wide or spacing looks off, do not send it to sponsors yet.
7. When the test looks acceptable, you can save it in Thunderbird with **File → Save As → Template**. For each sponsor, personalize the greeting and recipient before sending.

## Important

- The page images load from GitHub Pages. Recipients' email apps may hide remote images until they choose to display them.
- The page's primary button opens a message to `utcn.src@gmail.com`; the PDF link opens the dossier online.
- Send individually and personalize the opening for each company.
- Do not attach the large PDF by default; its link is already on the page.
