# TUCN Racing Team — sponsor page

This repository is published as a static GitHub Pages site. The `index.html` page is both the public sponsor presentation and the design to copy into an email. There is no separate sponsor outreach HTML template.

## Current files

- `index.html` — sponsor presentation, with the IESC 2026 photography and team logo.
- `templates/SENDING-GUIDE.md` — publishing and Thunderbird instructions for sending the rendered `index.html` page as the email body.
- `assets/` — web-sized copies of the logo and two IESC 2026 photos. Keep the original high-resolution files in `iesc 2026/`.
- `General Sponsorship Request/Mapa Sponsorizare.pdf` — sponsorship dossier linked from the page.
- `General Sponsorship Request/HTML/` and the root `Cerere_Sponsorizare...html` — earlier exports retained for reference.

## Sending the page by email

Follow [templates/SENDING-GUIDE.md](templates/SENDING-GUIDE.md). Open the published sponsor page, copy its rendered content, and paste it into an HTML Thunderbird message. Email clients may adjust some webpage styling, so send a test to yourself first.

## Updating the page

- The selected hero is `iesc 2026/MIH00522.jpg`; the team-at-work photo is `iesc 2026/MRS00323.jpg`. The page loads web-sized copies from `assets/`.
- Update event details and the Australia appeal only from confirmed team information.
- The current sponsor page is `https://tucnracingteam.github.io/general-sponsorship-request-2026/`.
- Keep the PDF as an optional click-through. It is large; before replacing the hosted copy, check its size and verify the link.

## Preview locally

Open `index.html` in a browser to preview the page. For email sending, use the published URL so its images and links resolve publicly.
